# Hypotenuse Formula

## Description

The Hypotenuse Formula is used to find the longest side (side c) of a triangle.

It uses the `sqrt()` and `pow()` function.

## Input Needed

Enter the following values:

- side a 
- side b

## How to run

- Open PyCharm
- Run the Python file
- Enter the required measurements
- Wait for the hypotenuse to be displayed

## Sample Output

**Input**

- side `a` = 3
- side `b` = 4

**Output**
- `c` = 5.00

OR

- `hypotenuse` = 5.00

*In the code, it will display a sentence rather than just the answer. So the Output would be:*

- The `hypotenuse` is 5.00
